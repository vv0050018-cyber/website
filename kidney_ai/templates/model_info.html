Model Specifications & Evaluation Metrics

Empirical test set evaluation metrics computed from trained Support Vector Machine and Decision Tree classifiers.

Support Vector Machine (SVM)

Primary Boundary Classifier

Maps radiomic feature vectors to an infinite-dimensional reproducing kernel Hilbert space using a Radial Basis Function (RBF) kernel ($\gamma = \text{scale}$, $C = 1.5$). Multi-class classification is executed via one-vs-one (OvO) decision functions with Platt sigmoid probability calibration.

Kernel: RBF Gamma: Scale Probabilities: Platt Calibrated

Decision Tree Classifier

Interpretable Hierarchical Tree

Constructed using the CART (Classification and Regression Trees) algorithm with Gini impurity metric. Calibrated to a maximum depth of 6 with minimum leaf samples to ensure clinical decision transparency and eliminate over-fitting.

Criterion: Gini Impurity Max Depth: 6 Min Leaf: 2

Radiomic Feature Extraction Pipeline (24 Dimensions)

Standardized numerical representation extracted from each processed kidney scan slice

1. Statistical Intensity Moments (6-D)
  • Mean Pixel Attenuation ($\mu$)
  • Standard Deviation ($\sigma$) & Variance
  • Skewness (Asymmetry of intensity distribution)
  • Kurtosis (Tail heaviness / calcification peak)
  • Shannon Information Entropy ($H$)
  • Total Normalized Intensity Energy
2. GLCM Texture Descriptors (5-D)
  • Angular Second Moment (ASM / Energy)
  • Texture Contrast (Sharpness of tissue edges)
  • Dissimilarity (Local gray-level variations)
  • Inverse Difference Moment (Homogeneity)
  • Inter-pixel Correlation Coefficient
3. Hu Invariant Moments (7-D)
  • Hu Invariant 1 (Spread around centroid)
  • Hu Invariants 2-6 (Scale & rotation invariants)
  • Hu Invariant 7 (Skew invariant for asymmetry)
  • Log-transformed for numerical stability
4. Radiomic Attenuation Thresholds (6-D)
  • Renal Stone Hyperdense Ratio (>220)
  • Renal Cyst Hypodense Ratio (<60)
  • Otsu Parenchymal Segmentation Area
  • Contour Circularity ($\frac{4\pi A}{P^2}$)
  • Convex Hull Solidity Ratio ($A / A_{hull}$)
